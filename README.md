# FIFA World Cup 2026

Site web consacré à la Coupe du monde de la FIFA 2026.

Le site présente la compétition, les pays hôtes, son histoire, quelques statistiques ainsi qu'un XI type composé de joueurs emblématiques.

## Technologies

* HTML
* CSS
* JavaScript
